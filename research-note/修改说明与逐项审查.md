# 逐项数学审查与修改说明

## 阅读口径

这是一份为学习而重写的英文 exposition，不是原创投稿稿，也不是作者认可稿。旧版 source-faithful blueprint 保留不覆盖。审查逐项覆盖旧稿64个编号数学条目（含定义、解析输入），另核查编号条目之间的关键推导。下面“注册定理仍引用”不是“未证明猜想”：它表示该定理在注册源码中有证明，但新稿没有将其全部底层解析构造独立重证明。没有进行本轮完整 Lean kernel replay 或独立人类同行评审。

## 最重要的修改

1. Introduction 改为数学背景→历史与文献→主大值定理→三种密度结论→文献覆盖边界→证明思想→依赖图→organization。归属为 Lewko，未声称解决全条带 density hypothesis。
2. 去掉 native/source/consumer/producer/closure 等实现口吻和无定义占位；统一 τ(n)、vartheta、A的特殊曲线记号、复内积和Fourier 2π。
3. 补齐finite trace比较的weighted Hölder、压缩trace convergence、sup-normalized smoothing、ratio sampling变分、Gamma detector窗口与weighted longcount。
4. 原错误Type-II因式分解和平滑负尺度sum已在旧版修正，新版保留正确证明。本轮另修正half-block端点解释和fourmask partition解释。
5. 经典第四矩、十二矩、highpeak和Ingham改为准确文献引用；保留适量推导和count/constant conventions，不重复长native重构。
6. 全局39/17改用full curve dominance再finitegrid，显著缩短，但在附录注明区别于原Lean global route。
7. 定理标题全部前导句，无theorem环境可选方括号；consequently和推导移到proof。真正相关的多区间结论及必要scale identities保留，不机械拆成多个空命题。
8. 未用到的公式取消编号，需引用的multiline用equation+aligned避免无标签的额外行编号；12条书目按首作者字母表、同作者年份排序。

## 是否被已有文献覆盖、是否有大幅更简单方法

Ingham支是经典结果；Kerr2019 Theorem6已给σ≥23/29时3(1−σ)/(2σ)，所以rightmostbranch这一部分不应称新。Tao–Trudgian–Yang系统收集更强的若干near-one点态界。本稿不作穷尽优先权判断，也未找到可直接替代整个注册middle-time bound的一个经典定理。39/17和Guth–Maynard的30/13只是global coefficients比较，不表示everyσ最优。学习价值主要在截断四阶矩、masked cubic、负谱mixedtrace和fixed detector family组合。

可以明显简化的是经典输入和endpoint组织，不是随意删去主证明的新解析估计。尤其unequal affine、restricted cubic、reflection row与smooth Mellin cover不能用一个“standard estimate”或一篇对象相邻文献冒充。

文献详见citation-audit.json，逐条书目信息与正文用途分开；无DOI条目不造DOI。
